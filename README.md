# Lazarus Master Terminal v12.0

AI-powered business optimization system for Hong Kong SMEs.

## 部署到 Railway

### 方法 1：用 Railway CLI（推薦）

1. 安裝 Railway CLI：
   ```bash
   npm install -g @railway/cli
   ```

2. 登入 Railway：
   ```bash
   railway login
   ```

3. 初始化 Railway 專案：
   ```bash
   railway init
   ```

4. 部署：
   ```bash
   railway up
   ```

### 方法 2：連接 GitHub 倉庫

1. 將此檔案上傳到 GitHub
2. 去 railway.app 連接你的 GitHub 倉庫
3. Railway 會自動部署

### 方法 3：用 Railway 網頁界面

1. 去 https://railway.app
2. 建立新專案
3. 選擇「Deploy from GitHub」或「Deploy from Template」
4. 上傳此檔案夾

## 功能

- 營銷工廠 2.0：生成多平台文案
- 貨源狙擊 2.0：供應鏈分析
- 成本漏洞：計算員工低效率損失
- 系統設定 2.0：自動回覆腳本

## 技術棧

- Frontend：HTML + TailwindCSS + JavaScript
- Backend：Node.js
- API：Manus AI API
